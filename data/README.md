# Data

The SkyView Aerial Landscape dataset (15 classes x 800 RGB images, 256x256) is not
committed. Place it here as:

```
data/Aerial_Landscapes/<Class>/*.jpg        # full dataset, 12,000 images
data/Aerial_Landscapes_Train/<Class>/*.jpg  # 640 per class (80 %)
data/Aerial_Landscapes_Test/<Class>/*.jpg   # 160 per class (20 %)
```

Source: SkyView: An Aerial Landscape Dataset (Kaggle, `ankit1743/skyview-an-aerial-landscape-dataset`).
